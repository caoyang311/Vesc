# 调试记录：滑膜观测器角度偶发剧烈跳变

状态：[OPEN]

## 症状
红色为强拖角度，蓝色为编码器角度，绿色为滑膜观测器角度。绿色角度整体跟随趋势，但存在偶发剧烈跳变，随后恢复。

## 可证伪假设
1. 角度在 ±π 或 0~2π 边界回绕，绘图未连续化。
2. 反电势/速度估计在过零、换相或低速时受噪声影响，导致 atan2 输入瞬时异常。
3. 极对数、方向或相位偏置处理不一致，跳变来自相位修正。
4. 角度变量被多个上下文重复写入，或读取时存在非原子更新。
5. 滑膜增益过大或积分限幅不足，观测器状态瞬时发散后恢复。
