# FOC七段式SVPWM算法方案设计

## 1. 文档目的

本文档基于当前MCU软件架构、TIM1底层配置和Pwm平台接口，确定采用**七段式空间矢量合成法**实现SVPWM。

本文档仅定义算法方案、接口边界、定时器适配、保护策略和验证要求，不直接修改C代码、不新增算法实现。

## 2. 当前硬件与软件配置

### 2.1 TIM1底层配置事实

根据当前`Core/Src/tim.c`：

| 项目 | 当前配置 |
|---|---|
| 定时器 | TIM1 |
| 输出通道 | CH1、CH2、CH3及CH1N、CH2N、CH3N |
| 输出形式 | 三组互补PWM |
| PWM模式 | PWM Mode 1 |
| 主输出极性 | 高有效 |
| 互补输出极性 | 高有效 |
| 主输出空闲状态 | Reset |
| 互补输出空闲状态 | Reset |
| 计数模式 | 中心对齐模式1 |
| 预分频 | 0 |
| ARR | 3599 |
| PWM频率 | 10 kHz，需结合当前时钟树最终确认 |
| 死区 | 100个定时器时钟计数，具体时间需结合TIM1时钟确认 |
| Break | 使能，低有效 |
| 自动输出 | 使能 |

当前TIM1的CCR1、CCR2、CCR3分别对应U、V、W三相PWM比较值。主输出和互补输出共享同一个CCR，由定时器硬件负责互补关系和死区插入。

### 2.2 当前平台接口

当前Pwm平台提供：

```c
bool Pwm_SetCompare(Pwm_ChannelType channel, uint16_t preload);
```

通道映射为：

```text
PWM_CHANNEL_U -> TIM1_CH1 / CCR1
PWM_CHANNEL_V -> TIM1_CH2 / CCR2
PWM_CHANNEL_W -> TIM1_CH3 / CCR3
```

SVPWM算法只负责产生三相比较值，不直接访问：

- `TIM_HandleTypeDef`。
- HAL通道宏。
- CCR寄存器。
- GPIO和Break寄存器。

SVPWM输出通过Pwm平台接口提交到TIM1。

### 2.3 快速控制执行域

当前架构规定：

```text
TIM1更新中断
  -> 读取三相电流
  -> Clarke
  -> 正余弦查表
  -> Park
  -> 电流控制器
  -> 反Park
  -> 七段式SVPWM
  -> 更新CCR1、CCR2、CCR3
```

该路径属于硬实时ISR，必须满足：

- 固定且有界的执行时间。
- 无动态内存。
- 无阻塞调用。
- 无标准数学库三角函数。
- 无不可控长度循环。
- 输出在安全范围内。
- 计算异常时不得产生超出ARR的比较值。

## 3. SVPWM输入输出定义

### 3.1 输入电压矢量

SVPWM输入使用Alpha-Beta静止坐标系电压：

```text
Valpha
Vbeta
```

输入采用实时直流母线电压进行归一化，定义如下：

```text
Valpha = V_alpha_command / Vdc_reference
Vbeta  = V_beta_command  / Vdc_reference
```

其中：

```text
Vdc_reference = Vdc_measured
```

线性调制区最大参考电压矢量幅值定义为：

```text
|Vref|max = (sqrt(3) / 3) × Vdc_reference
```

当前方案约束：

- `Vdc_reference`采用实时母线电压采样值。
- 母线电压采样无效时的安全处理暂不在本方案中定义。
- 最大线性调制比为`sqrt(3) / 3`倍`Vdc_reference`。
- 不允许进入过调制区。
- 暂不考虑电压指令限幅位置和责任模块。

代码实现时仍需保证正常有效输入不会使`T1 + T2`超过`T_pwm`。

### 3.2 输出比较值

输出为三相定时器比较值：

```text
CCR_U
CCR_V
CCR_W
```

范围必须满足：

```text
0 <= CCR_U <= 3599
0 <= CCR_V <= 3599
0 <= CCR_W <= 3599
```

建议输出结构体：

```c
typedef struct
{
    uint16_t compare_u;
    uint16_t compare_v;
    uint16_t compare_w;
} Foc_PwmCompareType;
```

SVPWM模块输出结构体后，由上层固定顺序调用：

```text
Pwm_SetCompare(PWM_CHANNEL_U, compare_u)
Pwm_SetCompare(PWM_CHANNEL_V, compare_v)
Pwm_SetCompare(PWM_CHANNEL_W, compare_w)
```

如果后续确认三相CCR必须严格同步生效，应在Platform层增加批量更新接口，例如`Pwm_CommitUpdate()`，由Platform负责影子寄存器和更新事件处理。

## 4. 空间电压矢量定义

### 4.1 六个有效矢量

三相两电平逆变器共有八个开关状态，其中六个为有效电压矢量：

| 矢量 | 开关状态`U,V,W` | 角度 |
|---|---|---:|
| V1 | 100 | 0° |
| V2 | 110 | 60° |
| V3 | 010 | 120° |
| V4 | 011 | 180° |
| V5 | 001 | 240° |
| V6 | 101 | 300° |

两个零矢量为：

| 矢量 | 开关状态 |
|---|---|
| V0 | 000 |
| V7 | 111 |

其中`1`表示对应桥臂上管导通状态，`0`表示对应桥臂下管导通状态。实际主、互补输出由TIM1硬件结合极性和死区生成，算法层不直接控制单个功率管。

### 4.2 六个扇区

Alpha-Beta平面分为六个60°扇区：

```text
Sector 1:   0°   <= angle < 60°
Sector 2:  60°   <= angle < 120°
Sector 3: 120°   <= angle < 180°
Sector 4: 180°   <= angle < 240°
Sector 5: 240°   <= angle < 300°
Sector 6: 300°   <= angle < 360°
```

每个扇区使用该扇区两侧的相邻有效矢量合成目标电压矢量：

| 扇区 | 相邻矢量 |
|---:|---|
| 1 | V1、V2 |
| 2 | V2、V3 |
| 3 | V3、V4 |
| 4 | V4、V5 |
| 5 | V5、V6 |
| 6 | V6、V1 |

实现时必须明确扇区边界的归属规则，禁止边界输入同时落入两个扇区。

## 5. 七段式合成原理

### 5.1 对称七段序列

一个PWM周期内使用两个相邻有效矢量和两个零矢量，典型对称序列为：

```text
V0 -> Vx -> Vy -> V7 -> Vy -> Vx -> V0
```

其中：

- `Vx`为第一个相邻有效矢量。
- `Vy`为第二个相邻有效矢量。
- `V0`和`V7`为零矢量。
- 序列前后对称，减少低次谐波并保持中心对齐特性。

以Sector 1为例：

```text
000 -> 100 -> 110 -> 111 -> 110 -> 100 -> 000
 V0     V1    V2    V7    V2    V1    V0
```

### 5.2 作用时间

设PWM周期为`T_pwm`，目标电压位于某个扇区内，两个有效矢量作用时间为`T1`和`T2`，零矢量总时间为`T0`：

```text
T1 + T2 + T0 = T_pwm
```

在线性调制区必须满足：

```text
T1 >= 0
T2 >= 0
T0 >= 0
```

对于扇区内角度`theta_s`，其中：

```text
0 <= theta_s < PI/3
```

代码实现不计算扇区内角度，也不调用三角函数。使用扇区局部Alpha-Beta分量直接计算作用时间。

定义：

```text
X = Ualpha_s
Y = Ubeta_s
```

其中`Ualpha_s`和`Ubeta_s`为当前扇区映射后的局部坐标分量。作用时间使用以下计数域公式：

```text
T1 = ARR × ((3/2) × X - (sqrt(3)/2) × Y)
T2 = ARR × (sqrt(3) × Y)
T0 = ARR - T1 - T2
```

当前代码中的固定系数对应为：

```text
sqrt(3)/2 = 0.8660254038F
sqrt(3)   = 1.7320508076F
3/2       = 1.5F
```

上述公式直接在TIM1计数域内计算，`ARR = 3599`。代码实现前后必须保持扇区局部坐标定义、`T1/T2`顺序和扇区作用时间表一致。

### 5.3 零矢量分配

推荐V1.0采用对称分配：

```text
T0_0 = T0 / 2
T0_7 = T0 / 2
```

对应的半周期时序为：

```text
T0/2 -> T1/2 -> T2/2 -> T0/2
```

由于TIM1采用中心对齐计数，软件不应在ISR中逐段切换GPIO或强制切换通道。算法只计算等效三相比较值，具体对称载波和互补输出由TIM1硬件完成。

### 5.4 作用时间到比较值

在中心对齐PWM中，推荐先将作用时间转换为三相导通时间，再转换为CCR：

```text
duty_u = T_on_u / T_pwm
 duty_v = T_on_v / T_pwm
 duty_w = T_on_w / T_pwm
```

```text
CCR_U = round(duty_u × ARR)
CCR_V = round(duty_v × ARR)
CCR_W = round(duty_w × ARR)
```

当前：

```text
ARR = 3599
```

因此：

```text
CCR_x = round(duty_x × 3599)
```

实际软件实现应统一采用定时器计数域计算，避免先进行不必要的多次浮点单位转换。

## 6. 扇区与时间计算方案

### 6.1 推荐实现方式

推荐采用**基于Alpha-Beta分量的三电平判定和时间直接计算**，不在快速路径中调用反三角函数、平方根或角度计算函数。

扇区号采用以下方法计算：

```text
U1 = Ubeta
U2 = (sqrt(3) / 2) × Ualpha - Ubeta / 2
U3 = -(sqrt(3) / 2) × Ualpha - Ubeta / 2
```

分别定义：

```text
A = (U1 > 0) ? 1 : 0
B = (U2 > 0) ? 1 : 0
C = (U3 > 0) ? 1 : 0
N = 4 × C + 2 × B + A
```

`N`到扇区号的映射为：

| `N` | 扇区 |
|---:|---:|
| 3 | 1 |
| 1 | 2 |
| 5 | 3 |
| 4 | 4 |
| 6 | 5 |
| 2 | 6 |

`N = 0`和`N = 7`为零矢量或边界异常状态，当前实现默认使用扇区1；正式代码应通过零电压特殊处理避免依赖该默认扇区。

建议流程：

```text
Valpha、Vbeta
  -> 扇区判断
  -> 获取扇区内相邻矢量
  -> 计算T1、T2
  -> 计算T0
  -> T1/T2/T0边界检查
  -> 根据扇区生成三相作用时间
  -> 转换为CCR_U/V/W
```

扇区判断仅使用Alpha-Beta分量、固定乘法和比较操作完成，不还原三相`U/V/W`电压，不调用`atan2f()`、`asinf()`、`acosf()`或其他角度函数。

### 6.2 扇区边界规则

推荐定义：

```text
Sector 1: 0°   <= angle < 60°
Sector 2: 60°  <= angle < 120°
Sector 3: 120° <= angle < 180°
Sector 4: 180° <= angle < 240°
Sector 5: 240° <= angle < 300°
Sector 6: 300° <= angle < 360°
```

边界测试至少覆盖：

```text
0°、60°、120°、180°、240°、300°、360°回绕
```

零电压矢量`Valpha=0、Vbeta=0`不依赖扇区结果，应直接产生三相50%占空比：

```text
CCR_U = CCR_V = CCR_W = ARR / 2
```

### 6.3 作用时间线性区保护

计算完成后必须进行：

```text
T1 = max(T1, 0)
T2 = max(T2, 0)
```

如果：

```text
T1 + T2 > T_pwm
```

由于本方案不允许过调制，正常有效输入的设计目标为：

```text
T1 + T2 <= T_pwm
```

代码实现时不采用过调制统一缩放作为正常控制策略。算法内部仍需保留`T1/T2/T0`边界检查，异常超限时按照SVPWM模块定义的故障输出策略处理。

## 7. 六扇区比较值生成

### 7.1 统一时间符号

建议定义：

```text
X = T1
Y = T2
Z = T0 / 2
```

在对称七段式中，三相占空时间可按照扇区映射生成。推荐使用固定查表或显式`switch`，禁止使用不可追踪的动态表索引。

### 7.2 扇区作用时间表

在采用`T1`为第一个相邻有效矢量、`T2`为第二个相邻有效矢量的约定下，三相上管导通时间可按以下形式生成：

| 扇区 | `T_on_U` | `T_on_V` | `T_on_W` |
|---:|---:|---:|---:|
| 1 | `Z + X + Y` | `Z + Y` | `Z` |
| 2 | `Z + X` | `Z + X + Y` | `Z` |
| 3 | `Z` | `Z + X + Y` | `Z + Y` |
| 4 | `Z` | `Z + X` | `Z + X + Y` |
| 5 | `Z + Y` | `Z` | `Z + X + Y` |
| 6 | `Z + X + Y` | `Z` | `Z + X` |

该表必须与代码中的`T1/T2`定义、扇区判定和开关状态编码保持一致。正式实现前应使用开关状态真值表逐项复核，不能仅依据表格直接编码。

### 7.3 比较值转换

设：

```text
T_on_x / T_pwm = duty_x
```

则：

```text
CCR_x = round(duty_x × 3599)
```

转换前需要：

```text
0 <= T_on_x <= T_pwm
0.0F <= duty_x <= 1.0F
```

任何超出范围的中间值必须先处理，再转换为`uint16_t`。

## 8. TIM1中心对齐适配

### 8.1 不执行软件七段切换

当前TIM1已经使用中心对齐模式，算法层不应在PWM周期内执行以下操作：

- 软件强制切换GPIO。
- 软件直接写入功率管开关状态。
- 使用延时模拟七段时序。
- 在ISR中循环等待每个矢量驻留时间。
- 通过HAL逐段启动或停止PWM通道。

算法层只计算一个PWM周期对应的三相CCR值，TIM1硬件负责：

- 中心对齐计数。
- PWM Mode 1比较输出。
- 主、互补输出生成。
- 死区插入。
- Break保护。

### 8.2 CCR更新一致性

当前`Pwm_SetCompare()`逐通道更新CCR1、CCR2、CCR3。SVPWM设计必须确认：

1. CH1~CH3的比较寄存器预装载是否使能。
2. CCR写入后在哪个更新事件生效。
3. 三个CCR连续写入期间是否可能出现半周期不一致。
4. ADC CH4触发是否与CCR更新存在竞争。

推荐接口演进：

```text
Foc_Svpwm_Calculate()
  -> 生成Foc_PwmCompareType
  -> Pwm_SetCompare(U)
  -> Pwm_SetCompare(V)
  -> Pwm_SetCompare(W)
  -> TIM1更新事件统一生效
```

如果底层无法保证统一生效，新增：

```c
bool Pwm_SetCompareTriple(const Foc_PwmCompareType * compare);
```

该接口应由Platform层实现，FOC算法层不得直接操作TIM1寄存器。

### 8.3 ADC采样窗口

当前ADC2和ADC3由TIM1 CH4比较事件触发。七段式SVPWM实施时应检查：

- `T1`、`T2`过小时是否仍有足够采样窗口。
- CH4触发是否落在有效矢量稳定区。
- 过零矢量期间是否可能触发无效采样。
- 低调制比时采样窗口是否满足ADC转换时间。
- 死区和最小脉宽是否改变有效矢量时间。

V1.0建议先采用固定采样点和线性调制区限制，不在第一版同时实现复杂的扇区自适应采样点重排。

## 9. 死区、最小脉宽和输出限幅

### 9.1 死区

TIM1硬件已配置死区，SVPWM模块不直接修改死区寄存器。死区引起的平均电压误差是否需要补偿，应根据：

- 死区时间。
- PWM周期。
- 功率器件导通压降。
- 电流方向。
- 电流采样精度。

单独评审。死区补偿不应在基础SVPWM实现中隐式加入。

### 9.2 最小脉宽

为了保证：

- 功率级可靠导通和关断。
- ADC采样窗口有效。
- 不产生过窄脉冲。
- 不因死区造成脉冲吞噬。

应定义：

```text
CCR_MIN
CCR_MAX
```

其中：

```text
0 < CCR_MIN < CCR_MAX < ARR
```

具体数值必须由功率级、死区、ADC采样和硬件测试共同确定，不在本方案中虚构固定值。

### 9.3 比较值安全限幅

推荐转换顺序：

```text
作用时间检查
  -> duty范围检查
  -> 最小脉宽约束
  -> 四舍五入
  -> uint16_t范围检查
  -> 生成CCR结构体
```

禁止将可能为负数或大于`ARR`的浮点值直接转换为`uint16_t`。

## 10. 异常和安全策略

### 10.1 输入异常

SVPWM边界需要定义：

- 输入指针为空。
- 输入为NaN或无穷值。
- `Valpha/Vbeta`超出归一化范围。
- 母线电压采样无效时，当前版本暂不定义专用安全处理。
- 线性调制区超限。
- 计算中间值超出预期范围。

当前版本暂不考虑电压指令限幅责任模块。代码实现仍需在SVPWM计算边界检查作用时间和CCR范围，防止异常中间值产生非法定时器比较值。

### 10.2 输出异常

任何情况下不得提交：

```text
CCR_U < 0
CCR_V < 0
CCR_W < 0
CCR_U > 3599
CCR_V > 3599
CCR_W > 3599
```

算法异常时应输出预定义安全比较值，或由上层进入PWM关闭流程。安全比较值、故障锁存和恢复策略属于MotorControl/System与Platform的联合设计。

### 10.3 硬件保护边界

Break输入、死区、互补输出关闭和自动输出属于TIM1硬件及Platform/Core职责。SVPWM不能替代硬件Break保护。

停机、故障和初始化阶段应使用预先定义的安全CCR值，并通过`Pwm_StopOutputs()`或系统故障流程关闭输出。

## 11. C Safety Coding Standard约束

SVPWM代码实施时必须满足：

- 输入和输出使用明确的结构体类型。
- 所有自动变量显式初始化。
- 所有指针参数的方向、空指针行为和所有权写入Doxygen。
- 不使用动态内存、递归、阻塞和不确定长度循环。
- 使用`float`时明确常量后缀`F`。
- 浮点到`uint16_t`转换前完成范围检查。
- 不混用有符号和无符号类型。
- 扇区判定和`switch`分支具有完整默认行为。
- 所有分支使用大括号，`if`与`else`成对。
- 不在算法层访问HAL、寄存器和GPIO。
- 查表、常量和配置数据使用只读对象。
- 静态分析发现必须分类处理，不得全局屏蔽。
- 扇区边界、作用时间边界和CCR边界必须有明确验证证据。

## 12. 验证计划

### 12.1 算法单元测试

- `Valpha=0、Vbeta=0`时三相输出为50%占空比。
- Alpha轴正向输入。
- Beta轴正向输入。
- 六个扇区内部典型点测试。
- 六个扇区边界测试。
- 正负电压指令测试。
- 最大线性调制深度测试。
- `T1=0`、`T2=0`、`T0=0`边界测试。
- 作用时间和占空比范围测试。
- 输出CCR边界测试。

## 13. 版本规划

### V1.0：基础七段式SVPWM

## 14. 结论

当前工程采用TIM1中心对齐、ARR=3599、10 kHz、三组互补PWM、PWM Mode 1、高有效极性和硬件死区配置。基于该硬件架构，SVPWM正式方案确定为：

> **七段式对称空间矢量合成，软件计算三相CCR，TIM1硬件完成中心对齐载波、互补输出、死区和Break保护。**

V1.0采用线性调制区、六扇区判定、`T1/T2/T0`计算、`T0`对称分配和三相CCR输出。软件不逐段切换GPIO，不直接操作功率管，不在ISR中等待矢量驻留时间。

在代码实现前必须冻结以下参数：

1. 实时母线电压采样值的接口和单位。
2. `sqrt(3) / 3 × Vdc_reference`对应的内部归一化系数。
3. 不允许过调制时的超限处理策略。
4. `CCR_MIN`和`CCR_MAX`。
5. 死区补偿是否纳入SVPWM。
6. CCR1~CCR3统一更新机制。
7. ADC CH4触发窗口与七段式有效矢量的对应关系。
8. 母线电压采样无效时的后续版本安全策略。
9. 输入异常和输出故障时的安全策略。
